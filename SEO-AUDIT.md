## Structured data limitations

- Organization and website identity are included. Verified LocalBusiness telephone/address/license fields are **not** included because the ZIP still contains sample contact data and concept-business placeholders.
- Schema uses only the service names and areas currently described by the website; these must be confirmed by the real business.
- FAQPage markup is for semantic parsers; Google retired FAQ rich results in 2026.

## Limits

- Rendering uses an in-memory Chromium preview with images/styles/scripts embedded because external or local `file://` navigation is blocked in this environment. It is not a Cloudflare deployment test.
- Social snippets depend on indexing and search-engine choices; no results placement is guaranteed.
- Sample mailto forms remain not backed by a live service endpoint.
- Google Search Console verification and sitemap submission have not happened.

## Launch and final-domain caveat

`https://river-valley-demo.pages.dev` is the configured canonical base. If the user later changes to a custom domain, update the nine canonical tags, Open Graph URL/image references, JSON-LD URL IDs, sitemap URLs, and robots.txt before launching. Domain-based canonical migrations should be accompanied by 301 redirects and Search Console verification.
